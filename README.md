# Trip Planner Mobile Advanced

React Native Expo app with:

- React Navigation routing
- Redux Toolkit auth state
- React Native Paper Material UI style
- JWT storage with AsyncStorage
- Axios connection to Spring Boot backend

## Install

```bash
npm install
```

## Run

```bash
npm start
```

## Backend URL

Edit:

```text
src/config/env.js
```

Android emulator:

npx expo start --clear
